E-COMMERCE

E-Commerce-Dashboard: Vertriebssteuerung in Echtzeit

Herausforderung

Die Vertriebsdaten waren auf mehrere Quellen verteilt. Das Team verfolgte seine Kennzahlen mit Verzögerung und hatte keinen ausreichenden Überblick über die leistungsstärksten Produkte und Kanäle.

Lösung

Konsolidierung der Daten mit SQL, Aufbereitung der Kennzahlen mit Python und Erstellung eines Tableau-Dashboards mit Filtern nach Zeitraum, Kanal, Produkt und geografischer Region.

Ergebnisse

-30%Verzögerung im Reporting
15%zurückgewinnbare Marge

Ein gemeinsamer Überblick über die Vertriebsdaten für die Verkaufsteams.

Tools und Technologien

  • SQL
  • Python
  • Tableau
  • Excel
SAAS

Churn-Analyse: Kunden mit Abwanderungsrisiko identifizieren

Herausforderung

Die Kündigungsrate stieg, ohne dass eine eindeutige Ursache erkennbar war. Das Unternehmen wollte schwache Signale vor der Abwanderung von Kunden erkennen.

Lösung

Explorative Analyse mit Python, Segmentierung der Kunden nach Produktnutzung, Bestandsdauer und Interaktionen mit dem Support sowie Entwicklung eines verständlichen Risikoscores.

Ergebnisse

22%identifizierte Risikokonten
-12%gezielte Churn-Rate

Ein priorisierter Maßnahmenplan für das Customer-Success-Team.

Tools und Technologien

  • Python
  • pandas
  • SQL
  • Jupyter
B2B-DIENSTLEISTUNGEN

Bereinigung und zuverlässige Aufbereitung einer Kundendatenbank mit 50 000 Zeilen

Herausforderung

Die Kundendatenbank enthielt Duplikate, uneinheitliche Formate und unvollständige Informationen. Die Teams konnten die Vertriebsleistung nicht zuverlässig messen.

Lösung

Profiling der Datenbank, Normalisierung der Felder, Erkennung von Duplikaten mit Python und Erstellung dokumentierter Prüfrichtlinien für künftige Importe.

Ergebnisse

-18%erkannte Duplikate
96%verwertbare Datensätze

Ein reproduzierbarer Prozess zur Qualitätsprüfung.

Tools und Technologien

  • Python
  • PostgreSQL
  • Excel
MARKETING

Messung der Leistung von Akquisitionskampagnen

Herausforderung

Zusammenführung der Werbe- und Vertriebsdaten, Definition gemeinsamer Kennzahlen und anschließend Erstellung eines automatisierten Reportings mit SQL und Tableau.

Ergebnisse

-25%Zeitaufwand für das Reporting
14%neu verteiltes Budget

Eine einheitliche Sicht auf die Akquisitionsstrecke.

  • SQL
  • Tableau
  • Looker Studio
  • Python
