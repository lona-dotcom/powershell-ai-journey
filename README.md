## 🚀 Objectif du Projet

> *"Allier la puissance de **PowerShell** et la flexibilité de **Python** pour créer des solutions intelligentes et automatisées."*

Ce dépôt est mon **laboratoire personnel** où j'expérimente, apprends et construis des outils combinant :

| Domaine | Compétences |
|---------|-------------|
| ⚡ **PowerShell** | Scripting avancé, administration système, automatisation Windows |
| 🐍 **Python** | Data science, machine learning, API, web scraping |
| 🤖 **IA augmentée** | Prompt engineering, modèles LLM, analyse prédictive |
| 🔧 **DevOps** | CI/CD, monitoring, infrastructure as code |
